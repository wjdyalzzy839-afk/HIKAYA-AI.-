1. الرؤية الأساسية

HIKAYA AI هو مشروع لبناء ذكاء اصطناعي متخصص في صناعة المحتوى التاريخي والجغرافي، مصمم ليكون العقل الإبداعي والبحثي والتقني لقناة حكاية وخرائط.

هدفنا بناء نموذج ذكاء اصطناعي خاص بنا من الصفر، دون الاعتماد على أوزان نماذج جاهزة أو واجهات API أو استدعاء نماذج شركات أخرى.

نريد امتلاك بنية النموذج وبيانات تدريبه وأدواته وطرق تطويره.

يبدأ المشروع بنموذج لغوي صغير، ثم يتطور تدريجيًا من خلال التدريب والاختبار والتحسين.
